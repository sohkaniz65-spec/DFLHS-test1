# 문학 수업자료 스튜디오

작품 하나(예: 윤동주 「쉽게 씌어진 시」)를 넣으면 다음 네 가지를 만들어 주는 **내 컴퓨터 전용** 웹앱입니다.

1. 교사용 교안: 자습서·자료 해석을 시구마다 응축한 필기 + 학교 필기(빨간색). 학교 필기와 어긋나는 자료 해석은 자동으로 빠지고 따로 목록으로 남음
2. 학생용 교안: 시 전문 + 넓은 행간 (수업하면서 채우는 용도)
3. 클리닉 테스트 30문항 (5지선다, 정답·해설지 따로)
4. 과제물 100문항 (5지선다, 정답·해설지 따로)

모든 교안과 문항은 **학교 선생님 필기(학교 필기 기준)** 를 최우선으로 삼습니다. 만들고 나면 문항을 한 개씩 필기와 대조해 자동으로 검수하고, 어긋나는 문항은 **검수 페이지**에서 수정안 적용·삭제·직접 수정으로 처리합니다. 다 처리해야 출력(PDF)이 열립니다.

## 처음 설치 (한 번만)

1. **Node.js 설치**: https://nodejs.org 에서 LTS 버전을 받아 설치합니다.
2. 이 폴더를 내 컴퓨터에 받습니다. (GitHub → Code → Download ZIP → 압축 풀기)
3. **Anthropic API 키**를 발급합니다: https://console.anthropic.com → API Keys. 결제 수단 등록이 필요합니다.
4. 실행합니다.
   - Windows: `start.bat` 더블클릭
   - Mac: `start.command` 더블클릭
   - 처음 실행하면 `.env` 파일이 열립니다. `ANTHROPIC_API_KEY=` 뒤에 키를 붙여 넣고 저장한 다음 다시 실행하세요.
5. 브라우저에서 http://localhost:4173 이 열립니다.

> 키 없이 화면과 인쇄 디자인만 보려면 `.env` 에서 `MOCK_CLAUDE=1` 로 바꾸고 실행하세요. (연습 모드, 가짜 데이터)

## 쓰는 순서

| 단계 | 할 일 |
|---|---|
| 자료실 | OneDrive 공유 폴더를 PC에 동기화한 뒤 **폴더 경로를 연결**합니다. 파일 **이름 목록만** 만들고 내용은 읽지 않으므로 500GB 폴더도 됩니다. 자습서처럼 이름에 작품명이 없는 자료는 검색칸에 "자습서"를 넣고 **모두 읽어 두기**를 한 번 눌러 둡니다. |
| ① 작품·자료 | **자료실에서 찾기**: 이름에 작품명(씌어진/쓰여진 등 다른 표기 포함)이 든 파일 + 읽어 둔 자습서 중 작품이 나오는 쪽을 찾아 줍니다. 안 읽은 파일은 체크하고 **읽기**를 누르면 그 파일만 내려받아 읽습니다. 원문을 확인하고 저장합니다. |
| ② 학교 필기 | 학생들이 보낸 필기 사진을 보면서 **음성으로 받아 적어** 저장합니다. 여러 번 나눠 넣어도 됩니다. **정리하기**를 누르면 STT 오타를 바로잡고 "대상 → 선생님 해석" 항목으로 나눈 초안이 나옵니다. 검토하고 **확정**합니다. |
| ③ 생성 | 4종을 생성합니다. 백그라운드에서 돌아가니 기다리는 동안 다른 탭을 봐도 됩니다. |
| ④ 검수 | 필기와 어긋나거나 품질 문제가 있는 문항이 올라옵니다. **수정안 적용 / 원래 문항 유지 / 직접 수정 / 삭제** 중에서 고릅니다. 삭제한 만큼 **새로 채우기**를 누르면 30·100문항이 다시 채워집니다. |
| ⑤ 출력 | 미리보기에서 인쇄하거나 **PDF 바로 저장**을 누릅니다. |

### 필기가 매주 늘어날 때
새 필기를 입력하고 정리·확정하면 필기 기준의 버전이 올라갑니다(v1 → v2). 이미 만든 교안·문항에는 **"필기 변경됨 · 재검수 필요"** 가 표시됩니다. **새 필기로 재검수**를 누르면 새 기준에 어긋나게 된 문항만 다시 검수 대상으로 올라옵니다.

### OneDrive 연결 방법
1. 웹 OneDrive → **공유됨** → 공유받은 폴더 → **내 파일에 바로 가기 추가**
2. PC의 OneDrive 앱이 그 폴더를 동기화합니다.
3. 파일 탐색기에서 그 폴더를 열고 주소창의 경로(예: `C:\Users\이름\OneDrive\국어자료`)를 복사해 **자료실 → 폴더 연결**에 붙여 넣습니다.
4. 새 자료가 생기면 **모든 폴더 다시 읽기**를 누릅니다. 바뀐 파일만 다시 읽습니다.

### 스캔본·손글씨
글자 정보가 없는 스캔 PDF나 사진은 자동 검색에 걸리지 않습니다. 중요한 것만 **Claude로 읽기**를 누르면 글자로 옮겨 줍니다. 손글씨 필기는 오독이 있을 수 있으니, 필기 탭의 **사진으로 초안 받기**로 초안을 받은 뒤 **반드시 직접 고쳐서** 저장하세요.

## 설정 (`.env`)

| 항목 | 설명 |
|---|---|
| `ANTHROPIC_API_KEY` | API 키 |
| `STUDIO_MODEL` | 기본 `claude-opus-5` |
| `STUDIO_EFFORT` | 생각 깊이 `low`~`max` (기본 `high`) |
| `STUDIO_FALLBACKS` | 안전 필터 오탐 시 다른 모델로 자동 재시도 (`on`/`off`) |
| `CHROME_PATH` | PDF 바로 저장에 쓸 Chrome/Edge 경로 (보통 비워 둬도 자동으로 찾음) |
| `MOCK_CLAUDE` | `1` 이면 연습 모드 |

## 데이터와 보안
- 자료·필기·생성 결과는 모두 이 폴더의 `data/` 안에만 저장됩니다. 백업하려면 `data/` 폴더를 복사하세요.
- 서버는 이 컴퓨터(127.0.0.1)에서만 열립니다. 인터넷에 공개되지 않습니다.
- Claude API 로는 생성에 필요한 부분(선택한 자료 조각, 필기, 원문)만 보냅니다.

## 개발
```
npm install
npm test          # HWP/HWPX 추출, 검색, 서식 테스트
npm run mock      # 연습 모드로 실행
```
구조: `server.js` (API) · `lib/extract` (HWP·HWPX·PDF 읽기) · `lib/search.js` (자료 찾기) · `lib/prompts.js`·`lib/pipeline.js` (생성·검수) · `public/` (화면, 인쇄 디자인 `print.*`)
